# PowerBI Dashboard - IT Academy

This repository contains Power BI dashboards developed during the IT Academy data analysis specialization.

The project focuses on analyzing transactional data through interactive visualizations, transforming structured datasets into business-oriented insights.

### Project scope
- Data modeling and integration in Power BI
- Creation of calculated measures using DAX
- Design of interactive dashboards to answer business questions
- Implementation of KPIs and performance indicators
- Data visualization focused on usability and clarity

### Key analyses
- Total transaction amount over time compared to yearly targets
- Monthly sales trends with identification of underperforming periods
- Average transaction value by year and by country (e.g., Germany)
- User-level analysis based on transaction behavior
- Product-level insights, including top-performing products and distribution patterns
- Geographic distribution of users and transactions

### Skills
- Power BI (data modeling, relationships, dashboard design)
- DAX (CALCULATE, AVERAGE, filters, conditional logic)
- KPI and business metrics definition
- Data visualization and storytelling
- Analytical thinking applied to business scenarios

### Notes
This dashboard is built on a transactional dataset inspired by a fictional commerce environment (thematic dataset based on Game of Thrones elements), where users perform purchases across different products, countries, and time periods.

The project emphasizes not only technical implementation but also interpretation of results and identification of meaningful business insights.
